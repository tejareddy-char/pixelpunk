A journey map shows the **whole experience** from the user's side, across every channel: website, app, email, support, even word of mouth.

## Before you start

- [ ] Pick **one persona** and **one scenario** (e.g. "Priya signs up and sends her first invoice")
- [ ] Gather research: interview notes, support tickets, analytics, reviews
- [ ] Invite people from design, product, engineering and support
- [ ] Set up the board in FigJam or Miro (copy the grid below)

## Template

**Persona:** [Name] · **Scenario:** [What they're trying to do] · **Goal:** [What success looks like for them]

| | 1. Discover | 2. Consider | 3. Sign up | 4. First use | 5. Ongoing use |
|---|---|---|---|---|---|
| **Doing** | [Actions they take] | | | | |
| **Thinking** | [Questions on their mind] | | | | |
| **Feeling** | 😐 [Emotion + why] | 🙂 | 😟 | 😀 | 🙂 |
| **Touchpoints** | [Google, friend, ad…] | [Website, reviews] | [Sign-up form, email] | [App, onboarding] | [App, support] |
| **Pain points** | [What goes wrong] | | | | |
| **Opportunities** | [How we could improve] | | | | |

Rename the stages to fit your product. Common alternatives: *Aware → Evaluate → Buy → Onboard → Use → Renew → Recommend*.

## How to run the workshop

1. **Set the scene (10 min).** Share the persona, the scenario and the research.
2. **Fill in "Doing" (20 min).** Walk through each step in order, using sticky notes.
3. **Add "Thinking" and "Feeling" (30 min).** Use real quotes from research wherever you can.
4. **Draw the emotion line (10 min).** Connect the feelings into a curve. The dips are where to focus.
5. **Mark pain points (20 min).** Note where users drop off, get confused or contact support.
6. **Brainstorm opportunities (30 min).** Use "How might we…?" questions for each big pain point.
7. **Prioritise (20 min).** Vote on the opportunities by impact and effort.

## Tips

- **Map the current state first**, before imagining the ideal future.
- **Base it on evidence.** Mark anything that's a guess so you can research it later.
- **Look at the dips in the emotion curve.** They usually point to the most valuable fixes.
- **Turn the top opportunities into tickets** or design tasks the same week, or the map will be forgotten.
